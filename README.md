# EasyClip

A real-time audio distortion plugin for electronic music production, offering four clipping algorithms for shaping and adding harmonic character to your sound.

🎥 [Demo Video](https://www.youtube.com/watch?v=7pT0tFm85ME)

## Features

- **4 Clipping Algorithms** — Soft Clip, Hard Clip, Foldback, and Downsample, each producing a distinct harmonic flavor
- **Core Parameters** — Drive, Threshold, Mix, and Output controls for precise tone shaping
- **Real-Time Audio Visualizer** — See your waveform distort as you tweak parameters

## Use Cases

- Adding harmonic richness and grit to bass synths
- Adding punch to drums to cut through your mix and add impact

## Tech Stack

- C++
- JUCE framework
- CMake
